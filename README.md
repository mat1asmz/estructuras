Dibuje un arreglo de 5 casillas con sus diferentes numeros y sus indices del 0 al 4, tambien una lista enlazada que son tres nodos conectados mediante flechas, donde cada nodo apunta al siguiente y el último apunta a null y una pila que es una representación de una torre de platos mostrando el tope, la base y las operaciones push y pop.
3 Apps:
Whatsapp creo que podria utilizar una lista enlazada para organizar los mensajes de una conversación, ya que cada mensaje aparece después de otro y hay una relación entre ellos.
Instagram creo que podria utilizar arreglos para almacenar grupos de elementos que necesitan estar organizados y ser consultados rápidamente, como información relacionada con publicaciones o imágenes que se muestran en determinadas posiciones.
Tiktok Creo que podría utilizar arreglos para organizar los videos que aparecen en el inicio, ya que los elementos pueden estar almacenados en diferentes posiciones y se pueden consultar rápidamente según el orden en que se muestran.
